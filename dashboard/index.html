How the ranges are built

Ranges come from the leave-one-out residual quantiles in log space (P10, P25, P75, P90). A row’s P25–P75 band is the printed range; the honesty table measures, held out, how often the real cap fell inside the stated bands. The model is cross-sectional: it says what a token would be worth if the protocol’s record stayed as it is, not whether or when a token is issued.

Set aside — the watchlist rule, applied board-wide

A protocol is set aside when it is an excluded category (CEX, Bridge, Canonical Bridge, Liquid Staking, Liquid Restaking, Restaked BTC), its name ends in a version marker, carries a whole word wrapped / staked / staking, or begins with an exchange’s name. These are products of a token that already trades, or versions of one.
