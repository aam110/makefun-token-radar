How the value is scored

implied value = TVL × category multiple × growth × maturity × breadth × dominance

Every factor comes from the snapshot's own figures — no protocol name is ever special-cased, and the same function scores every row.

  • Category multiple — the median market-cap-per-TVL of the live-token protocols in the same category, measured from this snapshot and shrunk toward the global median for small categories. A category with no live token takes the global median.
  • Growth — the protocol's 7-day TVL change, clamped to −50%…+100%, weighted at half strength.
  • Maturity — how long the protocol has run with no token, from its listing date to the snapshot date, capped at three years.
  • Breadth — a small premium for each extra chain the protocol runs on, capped at five.
  • Dominance — a premium for the protocol's share of its category's total TVL.
